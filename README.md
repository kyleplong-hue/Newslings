# Newslings

Daily world-news podcast concept for kids ages 5–10. The existing [`index.html`](index.html) is a website prototype.

For the product brief and spoken-script rules, see [`docs/BRIEF.md`](docs/BRIEF.md) and [`docs/TTS-SCRIPT-GUIDE.md`](docs/TTS-SCRIPT-GUIDE.md). For a Claude handoff and current-state caveats, start with [`CLAUDE.md`](CLAUDE.md).

Do not commit credentials, session data, or unlicensed audio assets. The podcast pipeline described in the brief is a plan, not an implemented feature in this repository.
